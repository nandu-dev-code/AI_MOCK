# AI Mock Interview System

A Flask-based mock interview platform with authentication, a dashboard, interview workflow placeholders, and report/admin views. The project is designed to be extended with Google Gemini, OpenCV, and MediaPipe integrations.

## Run locally

```bash
python -m venv .venv
source .venv/bin/activate  # Windows: .venv\Scripts\activate
pip install -r requirements.txt
python app.py
```

## Features

- User registration and login
- Session-based dashboard
- Interview, reports, and admin placeholders
- SQLite database by default
